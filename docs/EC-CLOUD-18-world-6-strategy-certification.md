# EC-CLOUD-18 — World 06 authoritative strategy certification

World 06 no longer relies on target-square clicks for official cloud progression. Its six server missions are certified chess positions with explicit strategic semantics.

## Certified concepts

1. Pawn structure: execute a central structural break.
2. Strong square: establish a supported knight outpost that cannot be chased by an enemy pawn.
3. Open file: activate a rook on a file containing no pawns.
4. Space: advance a pawn to restrict the opposing position.
5. Worst piece: activate an undeveloped piece from its home rank.
6. Plan: execute a central pawn break consistent with the position.

The legacy v191 presentation remains untouched. These definitions are the authoritative cloud equivalents used for future official progression and rewards.
